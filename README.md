## Overview

**VOICEPRINT** is an interactive, editorial digital product experience designed to showcase engineering depth, product intuition, voice-first velocity, and authentic founder grit. Rather than a conventional flat portfolio, VOICEPRINT combines:

1. **Origin Story & Engineering Narrative:** The journey from daily friction in hostel living to building scalable architectures.
2. **Interactive Project Exhibition:** In-depth case studies for:
   - **GoDuet:** Multi-restaurant dual-basket ordering platform with optimistic distributed cart state machines.
   - **Private Wellness Check-in:** Zero-knowledge client-side mental health tracker with native Web Crypto AES-256-GCM encryption.
   - **Floor Plan to 3D Viewer:** WebGL Three.js spatial extrusion from 2D architectural vectors at 60 FPS.
3. **Voice Lab (Wispr Flow Integration):** An interactive voice velocity simulator modeling developer friction reduction (~25–35 minutes saved per task).
4. **Growth Arena:** Interactive GTM campus experiment simulator ("Your Brain Has No Backspace").
5. **Ask Me (Gemma 4 AI Terminal):** Real-time conversational AI grounded in Siddharth's verified portfolio facts.
6. **Client-Side Cryptographic Vault:** Zero-knowledge note encryption utilizing AES-256-GCM with PBKDF2 key derivation.

## Security & AI Transparency

### 1. Client-Side Key Lifetime
Encryption keys are held in browser memory and are not persistently stored by the application. Refreshing the page, closing the tab or ending the session may discard the active key. Users must retain their passphrase or securely export their backup key to recover encrypted data later.

### 2. Local AI Fallback
When `GEMMA_API_KEY` is not configured or the remote provider is unavailable, VOICEPRINT uses deterministic responses grounded in its approved portfolio knowledge base. These responses are not generated by a live Gemma 4 inference session.

### 3. No Formal Security Certification
VOICEPRINT implements selected modern security practices, including AES-256-GCM authenticated encryption, PBKDF2-based key derivation, server-side credential isolation and API input validation. These implementations have undergone local automated testing but have not received independent security certification or a formal penetration test. VOICEPRINT does not claim SOC 2 or ISO 27001 certification.

### 4. AI Provider Privacy
When remote Gemma inference is enabled, recruiter questions are sent to the configured AI provider through the VOICEPRINT backend. Users should not submit passwords, encryption keys or other confidential information through Ask Me. Data handling is subject to the configured provider's privacy and retention policies.

## Technical Stack & Architecture

- **Frontend:** React 18, TypeScript 5, Vite 5, Tailwind CSS, Framer Motion, Canvas Confetti, Lucide React
- **Audio Experience:** Native Web Audio API synth (low harmonic resonance)
- **AI Gateway:** Google Gemma 4 (`gemma-4-26b-a4b-it` / `gemma-4-31b-it`) hosted on Google AI Studio with local grounded fallback engine
- **Security & Cryptography:** Browser Web Crypto API (AES-256-GCM, 12-byte random IVs, PBKDF2 with 600,000 iterations and SHA-256)
- **API Guardrails:** Express rate-limiting (30 req / 15 min), input sanitization, security headers (`X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: strict-origin-when-cross-origin`)

## Getting Started

### Prerequisites
- Node.js v18+ or v20+
- npm or pnpm

### Installation
```bash
git clone <repo-url>
cd VOICEPRINT
npm install
```

### Environment Configuration
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Fill in your Google AI Studio API key (optional for remote Gemma 4 inference; if omitted, the deterministic grounded fallback engine operates automatically):
```env
GEMMA_PROVIDER=google
GEMMA_MODEL=gemma-4-26b-a4b-it
GEMMA_API_KEY=your_google_ai_studio_api_key_here
```

### Development Server
```bash
npm run dev
```
Open `http://localhost:3001/` in your browser.

## Voice-Command Experience & Speech-to-Text

VOICEPRINT features a voice-first command terminal integrated into the **Ask Me** section, powered by the browser's native Web Speech API (`SpeechRecognition`) and routed through Gemma 4:

### 1. Natural Voice Commands Supported
- **"Explain GoDuet."** → Queries Gemma 4 for GoDuet multi-restaurant architecture and operational lessons.
- **"Show me my projects."** → Smoothly scrolls to the `#experiments` section.
- **"Explain the encryption system."** → Queries Gemma 4 for the client-side AES-256-GCM zero-knowledge vault.
- **"Tell me how I use Wispr Flow."** → Queries Gemma 4 for voice velocity and developer productivity gains.
- **"Explain the technology stack."** → Queries Gemma 4 for framework choices and architecture decisions.
- **"Go to the contact section."** → Smoothly scrolls to the `#contact` section.
- **Section Navigation:** "Go to origin", "Go to voice lab", "Go to growth arena", "Go to next chapter", "Go to top".
- **Confirmation-Guarded Actions:** Spoken actions such as "Reset conversation" or "Clear contact form" require explicit confirmation before execution to protect user state.

### 2. Multi-Language Speech Recognition
- **English (US/India):** `en-US` / `en-IN`
- **Hindi (हिन्दी):** `hi-IN`
- **Telugu (తెలుగు):** `te-IN`

### 3. Voice Controls & Accessibility
- **Microphone Button:** Beside Ask Me input with animated pulsing rings and soundwave visualization (`Alt+V` shortcut).
- **Editable Transcript:** Spoken words are displayed in the input field in real time, allowing users to review and edit before sending.
- **Controls:** Stop, Cancel, and Retry buttons.
- **Reduced Motion:** Adheres to `prefers-reduced-motion` settings.
- **Privacy Notice:** Microphone access is strictly on-demand; audio is never stored, recorded, or sent to any server. Browser Web Speech recognition is explicitly distinct from Wispr Flow desktop software.

### 4. Browser Compatibility Matrix
- **Native Support (Microphone Speech Recognition):** Google Chrome, Microsoft Edge, Safari (macOS/iOS), Brave, Android Chrome.
- **Fallback Simulation (Firefox / Unsupported Environments):** Interactive preset command chips allow testing all voice commands and routing without requiring browser Web Speech API.

## Automated Verification & Testing

Verifies all 6 primary natural voice commands, multi-language definitions, full section navigation, confirmation guards for destructive actions, and general query passthrough.

```bash

```
Verifies 256-bit key generation, Base64 export/import round-tripping, PBKDF2 key derivation (600,000 rounds), fresh 12-byte IV invariants, encryption/decryption integrity, and GCM authentication tag tamper detection.
